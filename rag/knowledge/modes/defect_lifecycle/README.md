# Defect lifecycle guidance

Typical states: New → Triaged → In Progress → Fixed → Retest → Closed (or Reopened).

## Severity examples

- **Critical** — data loss, payment failure, security breach
- **Major** — core flow blocked with workaround missing
- **Minor** — degraded UX with workaround
- **Trivial** — cosmetic

Always capture steps to reproduce, environment, and expected vs actual.
